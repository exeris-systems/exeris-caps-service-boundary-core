# ADR-015 — Codegen Emission Strategy (link stub)

**Authoritative copy:** [`exeris-tooling/docs/adr/ADR-015-codegen-emission-strategy.md`](https://github.com/exeris-systems/exeris-tooling/blob/main/docs/adr/ADR-015-codegen-emission-strategy.md)

ADR-015 defines the codegen pipeline that turns `@ExerisDomain` types and `@Action` methods into kernel-native handlers, sagas, OpenAPI, and schemas.

## Why this stub exists

`exeris-caps-service-boundary-core` provides `ApiSurfaceRegistry`, which is the direct runtime registration target for handlers emitted by `rest-emission` and `openapi-emission` codegen pipelines.
