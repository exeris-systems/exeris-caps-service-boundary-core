# ADR-024 — Capability Composition Model (link stub)

**Authoritative copy:** [`exeris-docs/adr/ADR-024-capability-composition-model.md`](https://github.com/exeris-systems/exeris-docs/blob/main/adr/ADR-024-capability-composition-model.md)

ADR-024 governs capability declaration (`@CapabilityModule`, `@Provides`, `@Requires`), the four-phase lifecycle (`initialize`, `ready`, `drain`, `terminate`), and build-time composition validation.

## Why this stub exists

`exeris-caps-service-boundary-core` is the Layer 1 Substrate Aggregate for the Service Boundary family. It declares `@Provides` for `ApiSurfaceRegistry`, `ServiceLifecycleHooks`, and `RequestContext`, and binds its lifecycle to `CapabilityLifecycleHooks`.
