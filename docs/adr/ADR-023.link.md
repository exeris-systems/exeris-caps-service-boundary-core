ADR-023 defines the three-valued licensing taxonomy for capabilities: `community`, `commercial`, and `enterprise-private`.

## Why this stub exists

`exeris-caps-service-boundary-core` is licensed as `commercial` (Exeris Commercial License, source-available, public visibility). Production use requires an active Platform SKU subscription or Platform-tier license. Code Detachment terms are governed by this taxonomy.
