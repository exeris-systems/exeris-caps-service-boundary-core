# ADR-006 — Spring-Free Kernel Boundary (The Wall) (link stub)

**Authoritative copy:** [`exeris-docs/adr/ADR-006-spring-free-kernel-boundary.md`](https://github.com/exeris-systems/exeris-docs/blob/main/adr/ADR-006-spring-free-kernel-boundary.md)

ADR-006 establishes the substrate-tier Wall: `exeris-kernel-spi` and `exeris-kernel-core` are strictly Spring-free.

## Why this stub exists

`exeris-caps-service-boundary-core` is the substrate aggregate for the Service Boundary family. Service Boundary SKUs (IDP, PIM, OMS, Headless CMS) execute kernel-direct without Spring in the request handling data plane. This capability must never introduce Spring, Netty, or servlet dependencies.
