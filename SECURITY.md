# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `main` (default branch) | Yes — no release has been published |

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in `exeris-caps-service-boundary-core`, please report it via GitHub Private Vulnerability Reporting or email security@exeris.eu.

Please do not open public issues regarding potential security vulnerabilities. Include details regarding the nature of the issue, affected endpoints or components, and steps to reproduce.
